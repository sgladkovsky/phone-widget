# Быстрый звонок — виджет для Flyme Auto

Android-приложение с виджетом для рабочего стола Flyme Auto. Каждый виджет — одна кнопка быстрого вызова. На рабочий стол можно добавить любое количество кнопок, каждая настраивается отдельно.

## Возможности

- **Виджет-кнопка** — нажатие инициирует звонок выбранному контакту
- **Выбор контакта** из телефонной книги при настройке виджета
- **Выбор иконки** — встроенные иконки или своё изображение из галереи
- **Несколько виджетов** — неограниченное количество кнопок на рабочем столе
- **Повторная настройка** — через приложение или долгое нажатие на виджет (reconfigurable)

## Сборка

Требования: JDK 17+, Android SDK 34.

```bash
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

## Установка и использование

1. Установите APK на устройство Flyme Auto
2. Предоставьте разрешения на **звонки** и **контакты**
3. На рабочем столе: удерживайте экран → **Виджеты** → **Кнопка звонка**
4. Выберите контакт и иконку, нажмите **Сохранить**
5. Повторите для каждой дополнительной кнопки

Для изменения настроек существующего виджета откройте приложение «Быстрый звонок» и выберите виджет из списка.

## Разрешения

| Разрешение | Назначение |
|---|---|
| `CALL_PHONE` | Прямой вызов по нажатию кнопки |
| `READ_CONTACTS` | Выбор номера из телефонной книги |

Если разрешение на звонок не выдано, виджет откроет экран набора номера (ACTION_DIAL).

## Структура проекта

```
app/src/main/java/com/flymeauto/phonewidget/
├── PhoneWidgetProvider.kt    # App Widget
├── WidgetConfigActivity.kt   # Настройка контакта и иконки
├── WidgetCallReceiver.kt     # Обработка нажатия
├── WidgetPreferences.kt      # Хранение настроек по widget ID
└── MainActivity.kt           # Список виджетов для редактирования
```
